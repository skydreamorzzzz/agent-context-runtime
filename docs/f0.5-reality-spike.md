# F0.5 Reality Spike

## Status and verdict

```text
F0.5: PASS
Gate A: PASS
Gate B: COMPLETE
Conditional closure: PASS
F1+: NOT STARTED
```

The initial Reality Spike independently demonstrated the real Claude
PASS-to-FAIL component and a real Git round trip in different repositories with
different Git bases. That evidence did not demonstrate end-to-end composition,
and the executable bit was not represented or restored. Its accepted verdict
was CONDITIONAL PASS.

The conditional closure resolved exactly those gaps. One new real Claude
incident's own passing captured state was restored after its observed failure
and recaptured with the same manifest hash. Executable state now participates
in canonical identity and was restored for tracked and selected-untracked
present regular files. The final F0.5 verdict is PASS.

This is a reality log for disposable probes, not a product implementation or a
frozen architecture. The initial machine-readable, manually reviewed derived
summary is [`verdict.json`](receipts/f0_5_reality_spike/verdict.json), which now
states its component-only claim limit. The final closure summary is
[`f0_5_conditional_closure/verdict.json`](receipts/f0_5_conditional_closure/verdict.json). Documentation
facts, offline tests, real Claude observations, and real Git observations remain
separate.

Persisted hook evidence followed:

```text
received payload
→ transient in-process inspection
→ explicit allowlist/sanitization
→ one immutable file per hook invocation
```

Raw payloads, prompt text, file content carried in hook payloads, transcript
paths, tool responses, environment values, and error bodies were not persisted.
`.env`, ignored files, environment state, and process state were not captured;
completeness is therefore degraded by design.
