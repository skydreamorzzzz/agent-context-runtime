# F0.5 Reality Spike

## Status and verdict

```text
F0.5: CONDITIONAL PASS
Gate A: PASS
Gate B: COMPLETE
F1+: NOT STARTED
```

The narrow core Demo path survived real Claude Code and Git execution. The
verdict is conditional because the observed Git executable bit is neither part
of the F0 captured-state manifest nor restored by the disposable restore probe.
Before an MVP implementation gate proceeds, the captured-scope contract must
either represent executable mode or explicitly exclude that behavior.

This is a reality log for disposable probes, not a product implementation or a
frozen architecture. The machine-readable, manually reviewed derived summary
is [`verdict.json`](receipts/f0_5_reality_spike/verdict.json). Documentation
facts, offline tests, real Claude observations, and real Git observations remain
separate.

Persisted hook evidence followed:

```text
received payload
→ transient in-process inspection
→ explicit allowlist/sanitization
→ one immutable file per hook invocation
```

Raw payloads, prompt text, file content carried in hook payloads, transcript
paths, tool responses, environment values, and error bodies were not persisted.
`.env`, ignored files, environment state, and process state were not captured;
completeness is therefore degraded by design.

## Reality contradictions and retained failures

| F0/documentation expectation | Observed reality | Impact and decision |
|---|---|---|
| project-local settings alone should be a clean isolated source | `--setting-sources local` ran lifecycle hooks but reported unauthenticated; the real authenticated run required `user,local` | project-local hooks worked, but user settings remained part of auth context; no user configuration values were inspected |
| current docs expose `prompt_id` | installed `2.1.144` did not; docs require `2.1.196+` | prompt correlation is unsupported on the tested version |
| each hook input can be treated as valid JSON | an early failed startup delivered empty SessionEnd stdin and exposed a logger robustness defect | logger records an anomaly without raw input; do not assume payload completeness on abnormal startup |
| F0 manifest captures state sufficient for tracked regular files | executable bit changed without manifest change and was not restored | overall verdict is CONDITIONAL PASS; revise or explicitly narrow before proceeding |
| a parallel tool batch demonstrates concurrent hook processes | requested parallel Reads were grouped, but observed hook intervals were sequential | concurrency remains unknown; no shared-journal conclusion |
| background tool post evidence identifies completion | post evidence arrived before the requested sleep duration and no later stable completion correlation appeared | background exact mutation attribution is degraded |

The preliminary failed/partial observations remain under
`docs/receipts/f0_5_reality_spike/gate-a-01/`; they were not deleted or promoted
to happy-path evidence.

## Known unsupported, degraded, and unknown boundaries

- **Unsupported by the tested manifest/restore:** executable mode.
- **Unsupported on installed CLI:** `prompt_id` correlation.
- **Degraded:** raw-payload completeness by privacy policy; background mutation
  attribution.
- **Unknown:** multi-session/concurrent-writer attribution, general hook process
  scheduling, shared append safety, production sequence allocation, Git GC
  retention, symlink/submodule/LFS/index semantics, medium-repository overhead,
  ignored files, environment/process/database/network restoration.
